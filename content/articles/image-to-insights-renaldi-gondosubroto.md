## Renaldi Gondosubroto, Software Engineer, SEEK

<https://www.linkedin.com/in/renaldigondosubroto/>

This lightning talk shows how to turn a single image into text using Python and
Azure AI Vision; covering environment setup, the minimal client call, and safe
result parsing. We’ll then zoom out to place this OCR step into a larger,
event-driven Azure architecture, highlighting security, observability, and easy
ways to scale.
